## Работа

В международном бизнес-сообществе организую мероприятия для его членов, в том числе хакатоны по всему миру. Выступаю ментором и координирую участников хакатонов.

Разработала CRM-систему в административной панели сообщества для собственных рабочих задач и оптимизировала часть процессов.

### Профессиональные навыки

- Организация международных ивентов и хакатонов.
- Координация и сопровождение участников.
- Менторство в рамках хакатонов.
- Оптимизация процессов и разработка внутренних инструментов.

## Практические навыки

- **Разработка:** небольшое приложение на Python и Flask.
- **Контроль версий:** Git, ветки, Pull Request и GitHub.
- **Среда запуска:** Dockerfile, образы, контейнеры и Docker Compose.
- **Автоматизация:** настройка сборки и HTTP-проверок в GitHub Actions.
- **Наблюдаемость:** Prometheus, Node Exporter, дашборды Grafana.
- **Документация:** Markdown, MkDocs Material, инструкции по воспроизведению.
